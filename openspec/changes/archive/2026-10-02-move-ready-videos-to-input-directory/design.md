## Context

CLI выбирает только видео непосредственно в --input; пути передаются ParseManager. Сейчас менеджер использует output/ready, что противоречит уточнённому запросу.

## Goals / Non-Goals

Исправить выбор каталога без изменения безопасного алгоритма переноса. Автоматическая миграция ранее готовых файлов и изменения OCR вне объёма.

## Decisions

ParseManager выбирает path.parent/ready для каждого источника. Поскольку CLI не обходит подпапки, это ready внутри --input. При прямом вызове менеджера с источниками из разных каталогов каждый получает собственную ready. Если path.parent.name.casefold() равно ready, используется сам родитель: повторная обработка сохраняет прежний путь без вложенных ready. Дополнительный аргумент входного каталога не нужен; ExportStorage продолжает отвечать за перенос, коллизии и очистку, менеджер — за условия успеха и прогресс.

## Risks / Trade-offs

- Имя входного каталога ready означает повторную обработку → тест сохраняет отсутствие вложенной ready.
- Входной каталог может быть недоступен для записи → прежняя обработка ошибки переноса сохраняет источник и экспортированные результаты.
- out/ready предыдущей версии содержит готовые видео → файлы не перемещаются автоматически.
