## Why

Пользователь хочет обрабатывать каталог видео без перечисления каждого файла и
использовать стандартные каталоги `in` и `out` без дополнительных параметров.

## What Changes

- Переименовать устанавливаемую консольную команду в `domino-video-parser.exe` по дополнительному запросу пользователя.
- Добавить `--input`: каталог видео, по умолчанию `in`.
- Сделать `--output` необязательным, по умолчанию `out`.
- Входной каталог просматривать без рекурсии; выбирать файлы с расширениями
  `.mp4`, `.mkv`, `.mov`, `.avi`, `.webm`, `.m4v`, `.mpeg`, `.mpg`, `.ts`, `.mts`, `.m2ts`
  без учёта регистра, сортировать по имени для воспроизводимого порядка.
- Отсутствующий, недоступный каталог или отсутствие видео — русское сообщение и код 1.
- **BREAKING:** удалить позиционные пути видео. Источники выбираются только из
  каталога; передача отдельных путей отклоняется с кодом 2.
- Сохранить обязательные `--fish-variant` и `--score-limit`, текущие проверки,
  формат JSON и запрет перезаписи. Обновить примеры запуска через `tools/run.bat`.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `video-game-export`: выбор входного каталога и значения путей по умолчанию.

## Матрица запуска

| --input | Источники |
|---|---|
| Не задан | Видео непосредственно в `in` |
| Задан | Видео непосредственно в указанном каталоге |

Позиционные пути видео в любом режиме — ошибка параметров, код 2.

Во всех строках: `--output` задан — использовать его; не задан — `out`.
Все относительные пути относятся к рабочему каталогу вызова, включая BAT.
Каталог вывода создаётся существующим механизмом записи; входной каталог не создаётся.

## Impact

Изменяются CLI, его тесты и README. По дополнительному запросу пользователя BAT переносится в tools/run.bat;
путь к .venv берётся из корня проекта. Передача аргументов сохраняется. ParseManager получает готовый список файлов как раньше.
Новые зависимости не нужны. Автоопределение правил и рекурсивный обход вне объёма.
