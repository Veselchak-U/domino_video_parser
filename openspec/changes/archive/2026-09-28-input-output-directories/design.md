## Context

CLI требует позиционные видео и --output. ParseManager уже принимает список Path,
а ExportStorage создаёт каталог вывода при записи. BAT сохраняет рабочий каталог.
Мотивация и режимы описаны в proposal.md.

## Goals / Non-Goals

Изменить только выбор входов и значения каталогов по умолчанию. Распознавание,
реконструкция, правила, формат файлов и автоматическое определение параметров
игры не затрагиваются.

## Decisions

- Console entry point в pyproject.toml называется domino-video-parser. Пакет
  остаётся domino-video, Python-модуль — domino_video; BAT вызывает модуль.
  После изменения переустановить editable-пакет и проверить новую команду.
- Позиционный аргумент videos удаляется; --input получает Path('in'),
  --output получает Path('out'). Argparse отклоняет прежние позиционные пути.
- Выбор файлов выполняется на границе CLI через pathlib; новый объект с состоянием
  и изменение ParseManager не нужны. Перед запуском manager список полностью
  собирается, фильтруется по расширениям и сортируется по (name.casefold(), name).
- Файлы других типов игнорируются; полный перебор декодерами всех файлов каталога
  создавал бы ошибочные отчёты для документов и изображений.
- Отказ чтения каталога — ошибка источника (1), позиционные пути —
  ошибка аргументов (2). Пустой набор не должен давать ложный успех.
- Для тестов CLI подменяется только граница ParseManager.run: проверяются реально
  отобранные пути и параметры. Успешный экспорт из каталога дополнительно проверяется
  существующей фикстурой наблюдений; BAT проверяется настоящим subprocess.

## Risks / Trade-offs

- Относительные пути при вызове из другого каталога → документировать и проверить
  сохранение рабочего каталога, не выполнять chdir.
- Разное перечисление файлов ОС → явная стабильная сортировка.
- Некорректный файл с видео-расширением → прежняя диагностика декодера и продолжение пакета.
- Редкий контейнер вне списка → явно документировать список расширений; рекурсия вне объёма.

## Migration Plan

После согласования — падающие тесты, правка CLI, проверки и README. Прежние команды
с явными файлами заменяются на --input; обновляются также приёмочный скрипт
и его примеры. По дополнительному запросу пользователя BAT переносится в tools/run.bat;
путь к .venv исправляется на родительский каталог относительно BAT.
Перенос существующих результатов и новые зависимости не требуются.
