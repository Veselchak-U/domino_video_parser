## Why

Пользователь запросил снизить начальный порог допуска двух GPU-процессов до 2000 MiB. Это позволяет использовать два процесса при свободной памяти от 2000 до 2047 MiB.

## What Changes

- Заменить начальный порог 2048 на 2000 MiB по явному запросу пользователя.
- Сохранить последующие проверки 1152 и 256 MiB, обработку ошибок и выбор одного при неизвестной памяти.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `gpu-ocr`: начальный порог свободной памяти для двух процессов.

## Impact

ocr.py, граничные тесты выбора, README и основная спецификация. Архитектура прежняя.

| Начальная память | auto/2, остальные проверки успешны | gpu-workers=1 | device=cpu |
|---|---|---|---|
| <2000 MiB или неизвестна | Один GPU-процесс | Один GPU-процесс | CPU |
| >=2000 MiB | Два GPU-процесса | Один GPU-процесс | CPU |
