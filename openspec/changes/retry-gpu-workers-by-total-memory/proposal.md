## Why

Пороги свободной VRAM ограничивают запуск по изменчивому снимку памяти. Пользователь выбрал расчёт по общему объёму с последовательными попытками уменьшения числа процессов.

## What Changes

- Начальное число: max(1, floor(total MiB / 1024)); свободная память не участвует. Оценка 1024 MiB согласована пользователем, но не гарантирует достаточную память или максимальную скорость.
- Неудачная загрузка или проба группы N освобождает всю группу; следующая попытка создаёт N−1 новых процессов. После неудачи одного используется CPU.
- **BREAKING**: --device gpu также допускает CPU после неудачной инициализации; фактическое устройство явно печатается.
- --gpu-workers сохраняет auto|1|2; явное число ограничивает начальный расчёт сверху. Auto больше не ограничен двумя.
- Неизвестный общий объём: пробуем один. CPU не опрашивает GPU. Выбор повторяется для каждого видео.
- Сбой уже начавшейся обработки остаётся ошибкой источника без автоматического повтора видео.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `gpu-ocr`: общий объём VRAM, повторные попытки и CPU после исчерпания попыток.

## Матрица поведения

| device | gpu-workers | Память известна | Память неизвестна | Все попытки неудачны |
|---|---|---|---|---|
| cpu | auto/1/2 | CPU без опроса | CPU без опроса | N/A: GPU не запускается |
| auto/gpu | auto | max(1, floor(total/1024)) | 1 | CPU с причиной |
| auto/gpu | 1 | 1 | 1 | CPU с причиной |
| auto/gpu | 2 | min(2, max(1, floor(total/1024))) | 1 | CPU с причиной |

Для каждой GPU-строки: успешная группа используется; неудача ведёт к N−1; недоступный DirectML сразу ведёт к CPU; прерывание останавливает пакет без CPU-повтора.

## Ответственности

| Компонент | Владеет состоянием | Читает/пишет | Выполняет | Явно не выполняет |
|---|---|---|---|---|
| gpu_memory | Снимок общего объёма | DXGI адаптера 0 | Чтение выделенной VRAM | Запуск процессов, опрос свободной памяти |
| DeviceOCR | Группа процессов, очередь нагрузок | Настройки и снимок | Расчёт числа, попытки, освобождение | Работа с DXGI, экспорт JSON |
| GPUWorker | Процесс и IPC | Команды и результаты | Модели, пробы, ограниченное ожидание | Выбор числа процессов |
| Pipeline/Manager | Источник и прогресс | Кадры, результаты | Обработка выбранным backend | Политика памяти |

## Impact

ocr.py, gpu_memory.py, gpu_worker.py при необходимости групповой пробы, тесты GPU, README и проверка GPU-установки. Новые зависимости не нужны. Формат JSON не меняется. Процессы создаются до кадров и полностью освобождаются перед повтором/CPU; очередь и порядок кадров остаются прежними.
