## Why

Диагностические отчёты смешиваются с игровыми JSON. Пользователь просит отдельную
подпапку report с сохранением перезаписи отчётов.

## What Changes

- Писать отчёты в `<output>/report/`, создавая подпапку автоматически.
- Сохранять существующие имена и атомарную замену отчёта по совпадающему пути.
- Игровые JSON остаются в `<output>/` с прежней защитой от перезаписи.
- Старые отчёты в корне каталога автоматически не перемещать и не удалять.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `video-game-export`: каталог диагностических отчётов.

## Матрица вариантов

| Состояние report | Результат |
|---|---|
| Отсутствует | Создать каталог и записать отчёт |
| Каталог существует | Записать или атомарно заменить отчёт |
| Файл вместо каталога или нет доступа | Диагностика, код 1, без ложных 100% |

## Impact

Путь записи отчёта в ParseManager, тесты путей и README. Формат JSON и выбор даты не меняются.
