# Проверка реализации 2026-09-29

290,47 сек. Правила withoutEggs, 50. Все шесть полных запусков завершились кодом 0,
полный игровой JSON совпал с tests/fixtures/sample_game.json.

Среднее явного одного — 100,65 сек, двух на стенде — 76,92 сек: уменьшение времени
примерно на 24%, производительность примерно в 1,31 раза выше. VRAM относится ко
всей карте, включая другие приложения; RSS суммируется по процессам и может
повторно учитывать общие страницы. nvidia-smi опрашивался примерно раз в секунду.

Реальные auto-запуски увидели 2032 и 1869 MiB свободной памяти до загрузки моделей
и корректно ограничились одним процессом. Реальный допуск двух при всех порогах
на этой машине в текущем состоянии не подтверждён. Пользователь явно разрешил
стенд с подменой только memory probe на 4096 MiB; остальной код и модели в обоих
двухпроцессных запусках — реальные. Перед стендом реально свободно 1872 и 1952 MiB.
Порог приложения не изменён. Выбор двух при граничных снимках, отказ при недостатке,
unknown, неоднозначном устройстве и сбое второго проверены автоматическими тестами.

Отдельно фактический GPU OCR кадра с подменой телеметрии на unknown успешно прошёл
в одном процессе и прочитал четыре имени. DXGI-идентификаторы реальной карты
сопоставились с nvidia-smi. Проба установки через `python -m domino_video.ocr`
прошла в GPU-окружении. Тесты Windows module/EXE/BAT и spawn включены в pytest.

Тесты покрывают аварийный выход, завершение всех ожидающих Future, таймаут старта,
принудительную остановку зависшего процесса, отмену очереди, возврат к первому,
новый источник после ошибки, порядок и лимиты очереди при одном/трёх CPU-работниках
и двух реальных процессах с тестовым OCR-адаптером. TTY и перенаправление проверены
на отсутствие статуса перед OCR и сохранение времени инициализации.
