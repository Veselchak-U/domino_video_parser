## Реальный OCR и контрольное видео

Источник: `in/Record_2026-09-28-13-58-19_ef23194d097aa6e1b107d0f095c4226c.mp4`,
290,47 с. SHA-256 до/после:
`09d33287088535cfd2c06170d7741a38e008a2e8b60dc91c4f06a15ae9fbe065`.
Разбирались временные копии; оригинал остался во входном каталоге.

Общие параметры: withoutEggs, scoreLimit 50, workers 24, прежние модели и пороги.
CPU: RapidOCR 1.4.4, ONNX Runtime 1.30.0, PyAV 18.1.0.
Настоящий GPU: run.bat, подготовленная .venv-gpu, DirectML 1.24.4,
адаптер 0, gpu-workers 2. Сеть для загрузки моделей не требовалась.

| Проход | Полное время вызова CLI | Результат |
|---|---:|---|
| CPU до изменения | 111,315 с | код 0 |
| CPU после изменения | 43,127 с | код 0 |
| DirectML после изменения, итоговый код | 44,668 с | код 0 |

Замеры выполнены последовательно, без одновременных тяжёлых тестов.
CPU ускорился в 2,58 раза в одном сравнении; это не гарантия для других видео.
GPU до изменения в этих условиях не замерялся. Итоговый GPU-проход повторён
после уточнения границ позднего счёта; первый GPU-проход занял 44,660 с.

В обоих устройствах сохранены 3 кона и 72 действия, JSON полностью совпадает
между CPU и настоящим DirectML. JSON Schema и GameValidator проходят.
После замены только имён по номерам мест документ целиком равен ручному
sample_game.json: раздачи, исполнители, стороны, пасы, результаты, итог партии.
Имена отдельно не приравнивались к старому мелкому OCR: источник теперь
финальные карточки, нижний игрок имеет настоящий ник вместо You.

Основной проход: 575 кадров без OCR. Адресное чтение: 79 кадров,
3 интервала native-анимации. Попытки имён только на 287,10–288,11 с;
послеконовые счета сохранены, периодическое чтение текста отключено.
Два частично читаемых имени дают предупреждения; код остаётся 0.
PNG диагностических имён побайтово соответствуют исходным областям таблицы.

Полные результаты и измерения сохранены локально в .analysis/fast-recognition:
baseline, optimized, gpu, *-metrics.json, validate_result.py, compare_devices.py,
check_samples.py. Эти диагностические файлы не входят в приложение.
