# Порядок применения правил проекта

Правила проекта уточняют работу в репозитории и не отменяют системные
ограничения, разрешения среды и явные указания пользователя.

Приоритет проектных источников:

1. Правила этого каталога.
2. [Контекст и обязательные требования](../../AGENTS.md).
3. Применимые [проектные скиллы](../skills/).
4. Общие рекомендации, если проектные источники не определяют решение.

## Чтение по задаче

На старте сессии прочитай AGENTS.md и этот файл. До соответствующего действия
прочитай применимые подробности:

| Работа | Правила |
|---|---|
| Изменение поведения, план или реализация | [OpenSpec](OPENSPEC_RULES.md) |
| Написание кода | [Код](CODE_WRITING_RULES.md) |
| Архитектура или ревью | [Ревью](REVIEW_RULES.md) |
| Создание или запуск тестов | [Тестирование](UNIT_TEST_RULES.md) |
| Поиск и чтение ресурсов, ссылки | [Инструменты](TOOL_USAGE_RULES.md) |
| Подготовка коммита или публикации | [Коммиты](COMMIT_STRUCTURE_RULES.md) |

Не загружай все правила и скиллы для каждой задачи. Прочитанные файлы используй
повторно в пределах сессии; перечитывай после изменения, при признаках внешней
правки или утрате содержания из контекста. Обрезанный вывод дочитывай.

Используй фактически существующие инструменты и скиллы. Отсутствие
неприменимого инструмента не блокирует задачу. При расхождении кода,
спецификаций и плана покажи его; существенный выбор поведения согласуй.
