# Диагностика реконструкции

В техническом отчёте `games[].reconstruction_diagnostics[]` содержит `code`,
`message`, `game`, `round`, `event`, `time`, `details`. Номера начинаются с 1,
время указано в секундах исходной записи. Неизвестные значения — `null`.
Отказ до выделения партии сохраняется в корневом `reconstruction_diagnostics`.
Соответствующая запись `errors[]` также содержит код и фактическое время.

| Код | Причина |
| --- | --- |
| `no_supported_game` | Не найдена поддерживаемая партия |
| `invalid_player_names` | Не распознаны четыре различных имени |
| `incomplete_round` | Неполная запись кона |
| `missing_start` | Не наблюдалось начало розыгрыша |
| `duplicate_stones` | Камень учтён несколько раз |
| `unconfirmed_remaining` | Не подтверждены конечные остатки |
| `missing_stones` | Не хватает камней, исключение не удалось |
| `unresolved_events` | Неизвестные или противоречивые события |
| `no_consistent_sequence` | Перебор не дал согласованной последовательности |
| `search_state_limit` | Превышен предел 4096 состояний кона |
| `reconstruction_combination_limit` | Превышен предел 128 сочетаний конов |
| `all_candidates_invalid` | Все полные варианты отклонены игровыми правилами |
| `multiple_valid_reconstructions` | Найдено несколько допустимых вариантов |
| `score_missing` | Не прочитан итоговый счёт |
| `score_conflict` | Табло расходится с вычисленным счётом |
| `score_limit_conflict` | Лимит табло расходится с параметром запуска |
| `reconstruction_failed` | Общий отказ без специализированного кода |

Для `no_consistent_sequence` поле `details.first_failure` указывает первое
обнуление вариантов, `details.events` содержит трассу событий с числами
`states_before` и `states_after`. Причины в `rejections`:

| Код | Отклонённая ветвь |
| --- | --- |
| `unknown_player` | Исполнитель неизвестен |
| `hand_capacity_exceeded` | Рука превысила бы семь камней |
| `initial_hand_conflict` | Исполнитель противоречит прочитанной начальной руке |
| `prior_pass_conflict` | Камень противоречит ранее сделанному пасу |
| `illegal_pass` | Пропускающий игрок имеет подходящий камень |
| `geometry_conflict` | Выбранный край противоречит расположению камней |
| `endpoint_mismatch` | Значение камня не подходит к концу цепочки |
| `hand_counter_conflict` | Повторные показания счётчика противоречат числу ходов |
| `incomplete_deal` | После обработки событий восстановлены не все руки по семь |

На причину сохраняются полный `count`, до двух `examples` и
`omitted_examples`. Это количество отброшенных ветвей, а не вероятность
первопричины. Ошибка чтения более раннего события может проявиться только
на последующем ходе. Для завершения раздачи без конкретного события его номер
и время остаются `null`.

`warnings[].code = start_position_conflict` означает несовместимую с позицией
события метку захода; это предупреждение не исправляет событие и не отбрасывает
ветви. Список ошибок валидатора ограничен пятью примерами, мест пропуска —
восемью; количество опущенных записей указывается отдельно.

Алгоритм восстановления не изменён. Проверки нового кода и прогоны видео
отложены по указанию пользователя.
